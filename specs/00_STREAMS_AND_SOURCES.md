## Podcasts

### Approche technique

Les podcasts sont distribués via des flux RSS standards.
Deux approches pour l'app :

#### Option A : iTunes Search API (gratuit, sans clé)

- Endpoint: `https://itunes.apple.com/search?term=QUERY&media=podcast&country=fr`
- Retourne : nom, auteur, artwork, et surtout **feedUrl** (URL RSS)
- Pas de rate limit officiel, mais raisonnable (quelques requêtes/sec)
- On parse ensuite le RSS pour lister les épisodes avec leurs URLs audio

#### Option B : Podcast Index API (gratuit, open-source)

- Site: https://podcastindex.org
- Nécessite une clé API (gratuite)
- Plus complet que iTunes, base de données communautaire

#### Option C : Flux RSS directs (hardcodés)

Pour des podcasts populaires français, on peut hardcoder les flux RSS :

| Podcast | Source | RSS Feed |
|---------|--------|----------|
| France Inter - Le 7/9 | Radio France | `https://radiofrance-podcast.net/podcast09/rss_10241.xml` |
| France Culture - Les Matins | Radio France | `https://radiofrance-podcast.net/podcast09/rss_10075.xml` |
| France Info | Radio France | `https://radiofrance-podcast.net/podcast09/rss_22647.xml` |
| Hugo Décrypte | Indépendant | Via iTunes Search API |

### Recommandation

**Option A (iTunes Search API)** est la plus simple à implémenter :
pas de clé, pas d'inscription, couverture quasi exhaustive.
On peut la combiner avec quelques flux RSS hardcodés pour les podcasts
Radio France les plus populaires.

## Notes légales

- Les streams Radio France sont publics et gratuits (service public)
- Les streams privés (RTL, NRJ, etc.) sont exposés publiquement par
  les radios elles-mêmes pour les lecteurs web tiers
- Les podcasts sont distribués intentionnellement via RSS pour être
  consommés par n'importe quelle application
- Aucune restriction de géoblocage connue pour ces streams depuis Israël
  (sauf potentiellement certains contenus vidéo, non concernés ici)
